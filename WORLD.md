# Мир из оригинала

`original-world.json` содержит извлечённые из локального `elma.res` 54 основных
уровня и дополнительную запись меню «More Levels». Никакие вершины не придуманы:
сохранены исходные double-координаты, порядок полигонов и вершин, флаги травы,
объекты и декоративные картинки. Названия сохранены буквально (включая
`Animal Fram` в оригинальном DESCLIST.TXT).

Повторить извлечение:

```sh
python world.py --res /путь/elma.res --exe /путь/elma.exe
python verify_world.py
```

Проверка требует зависимостей из requirements.txt и той же сборки EXE, что physics oracle.
Она исполняет машинный код оригинала; заменены только чтение файла, выделение памяти
и проверка stack cookie. Алгоритм декодирования и чтения записей исполняется без замены.
Совпали 72000 байтов каталога ресурсов и все значения/длины 1121 полигонов,
421 объектов и 1177 декоративных картинок.

## Доказательства формата

- `0x140140010`: count uint32, 3000 записей каталога по 24 байта; имена16,
  размер uint32, смещение uint32. На смещении72004 маркер `0x1490ff`.
- `0x140140110..0x140140167`: XOR-раскодирование каталога с signed16 состоянием.
- `0x140116f00`: внутренний формат `@@^!@`; заголовок130 байтов,
  затем double-счётчики полигонов и объектов. Дробная часть счётчика
  намеренно отбрасывается оригинальным `cvttsd2si`.
- `0x1400ddd30`: флаг травы int32, количество вершин int32, пары double x/y.
- `0x1401132d0`: x/y double, тип/гравитация/анимация int32.
- `0x140113950`: три строки по10 байтов, x/y double, дистанция/клиппинг int32.
- Названия уровней — ресурс DESCLIST.TXT; соответствие имён файлов —
  таблица EXE с14-байтовыми записями, начинающаяся с `nulla.leb`.

## Границы

JSON сохраняет координаты файла: построитель физической геометрии оригинала
инвертирует Y и исключает полигоны с ненулевым grass. Эти преобразования должны
выполняться потребителем; парсер их не скрывает.

В конце каждого LEB остаётся696 байтов, не используемых проверенными читателями
геометрии и декора. Их семантика не восстановлена. Проверка не подменяет полноценную
загрузку уровня, проверку целостности, построение сетки столкновений или геймплей.
В каталоге также присутствуют138 внешних POT14 уровней challenge/tutorial; они
проиндексированы, но не включены в список55 внутренних уровней. Растровые изображения
декора по указанным именам ещё не восстановлены.
